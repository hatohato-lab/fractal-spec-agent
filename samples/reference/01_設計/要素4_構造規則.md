# 要素4：構造規則 — 枠（オラクルが検査する対象）

上へ戻る: [00_枠](../00_枠.md)

| # | 規則 | 内容 |
|---|---|---|
| 4-1 | 1枚1画面 | 各ファイルは約40行以内。超えるなら子に分割する |
| 4-2 | 枠は2〜9行 | 枠の表の要素数は2〜9。上限は人の把握限界（7±2）に合わせる |
| 4-3 | 同形式の反復 | 全ノードが同じ節構成（タイトル→戻るリンク→表→掘るリンク） |
| 4-4 | 抽象度の単調降下 | 深く掘るほど具体的になる。同じ抽象度の繰り返しは禁止 |
| 4-5 | リンク完全性 | 「開く」リンクの先は必ず存在する。孤児ファイルも作らない |
| 4-6 | 未知語の定義義務 | 専門用語の初出は、用語.md に定義が無ければならない |
| 4-7 | 図の規則 | 00_枠に全体構成図必須。UMLを対象で使い分け。横向き（LR）禁止 |
| 4-8 | 配置の規則 | 00_入力の不足.md を置く。設計は01_設計/、用語.mdは02_学習/ に置く |
